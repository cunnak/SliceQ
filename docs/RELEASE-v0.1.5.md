# SliceQ v0.1.5 — 深色界面

## 新功能：界面主题

设置页底部新增「**外观**」，三档可选：

| 选项 | 说明 |
|---|---|
| **跟随系统**（默认） | 随 Windows 的浅色/深色设置自动切换 |
| 浅色 | 保持原来那种亮色界面 |
| 深色 | 中性深灰（`#1e1f22` 底），不是纯黑 |

改完之后**立即生效**（界面会重建一次，当前所在页面保持不变）。

> ⚠️ 顺带一个变化：浅色模式从 Qt 的**原生 Windows 11 风格**改成了 Qt 自绘的
> `Fusion`。原因是原生风格里有一部分由系统绘制、**不理会深色样式**，
> 深浅切换时观感会跳。代价是浅色看起来不再那么"原生"——
> 实测与改造前的像素差异只有 6~21/255（圆角、边框这类细节）。

---

## 这次改了什么（技术上的）

改造前，界面的颜色是**散在 9 个文件、91 处 `setStyleSheet` 里的硬编码**，
`MUTED = "#888780"` 这种常量还在 **6 个文件里各写了一遍**。
深色做不成的根本原因就在这里 —— 颜色没有单一来源。

这版：

- 新增 `sliceq/ui/theme.py` —— **语义色板**（按用途命名，不按色值）+
  `QPalette` + 全局样式表
- **91 处硬编码全部收敛**，`sliceq/ui/` 下硬编码颜色残留 **0**
- **补上了 `QPalette`** —— 原来完全没用过它，而滚动条、右键菜单、
  表格空白区、提示框这些**不吃 CSS** 的控件都靠它上色
  （只写样式表的话，深色界面上会到处露出浅色块）

## 对你有什么影响

- **手上的一切都不变**：配置、模型、历史任务、导出产物，都不受影响
- 默认是「跟随系统」—— 如果你的 Windows 是浅色，打开还是原来那样
- 想换：设置页 → 外观 → 界面主题

## 已知限制

- 切主题时**不会**改变已经打开的导出/复制对话框（它们是独立窗口），
  下次打开才是新主题
- **有分析在跑时不能切主题**（会弹窗说明）—— 重建界面会把进度显示清空
- 字幕样式页的那块**深色预览底板刻意不跟主题**：它模拟的是视频画面，
  不是窗口面板，浅色主题下也保持深色，这样才看得出白字幕压暗场的效果
