# SliceQ v0.1.0

> 首个公开版本。阶段 0~5 的功能全部完成并通过验收。

**SliceQ** 是一个 Windows 桌面应用：把一场几小时的直播录像，自动找出高光片段、
切好、配上字幕，导出成可直接发布的内容，以及能继续精修的时间线
（剪映草稿 / 达芬奇 OTIO）。

---

## 这个版本能做什么

- **导入**：本地视频拖放；B 站等 URL（yt-dlp）
- **本地转录**：FFmpeg 内置 whisper，**零 API 成本**，含幻觉重复清理
- **两段式分析**：粗筛（文本信号，把几小时压到几十个窗口）→ 多模态精析（判高光、给理由与标题）
- **成本可见**：开始前给预估上限 → 粗筛后唯一确认点 → 事后对账
- **切片**：每条候选一个独立 MP4；可选淡入淡出、BGM 自动闪避人声、自动选封面
- **字幕**：ASS 样式系统（字体 / 配色 / 描边 / 双语对照），同时产出 SRT
- **文案**：每条切片的标题与简介
- **批量**：多条候选并发；多个录像排队
- **三通道导出**：剪映草稿 / 达芬奇 OTIO / 降级包

## 系统要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| 磁盘 | 程序 60MB + **首次启动另需约 1.8GB**（FFmpeg 与 whisper 模型） |
| 其他 | 无需安装 Python；无需管理员权限 |
| 网络 | 首次启动需下载；URL 导入需联网；精析需访问模型端点 |

## 安装

1. 下载本 Release 附件中的 `SliceQ.exe`
2. 放到任意目录，双击运行（**绿色单文件，免安装**）
3. Windows 可能提示"未知发布者"—— 本版本未做代码签名，点"更多信息 → 仍要运行"

首次启动按提示完成三件事：填 API Key → 装 FFmpeg → 下 whisper 模型。
详见 [README 的「首次启动」一节](../README.md#首次启动要准备的三件事)。

## ⚠️ 已知限制（请如实预期）

这一版是**功能完整但验证面尚未铺满**的首个版本，以下问题已知：

| # | 限制 | 影响 |
|---|---|---|
| 1 | **未做代码签名** | Windows SmartScreen 会警告；企业环境可能被拦 |
| 2 | **剪映的成片需手动导出** | 剪映 7+ 已无法由外部程序触发渲染，属设计约束不是缺陷 |
| 3 | **字幕样式不跟随导出** | 剪映用自身默认样式；达芬奇用并行 SRT。已写入导出界面与导入说明 |
| 4 | **剪映 12.x / 13.x 未验证** | 本版本只在剪映 11.5.3 上验证过；更高版本格式变化无法预知 |
| 5 | **达芬奇导入需按说明操作** | 首次会弹「找不到片段」（`.otio` 格式本意）；字幕需用"按时间码插入"，直接拖会整体提前约 0.5 秒 |
| 6 | **内容审核可能拦截口语素材** | 模型侧行为，同一素材两次运行的结果可能不同 |
| 7 | **删任务不清理 work 目录** | 会残留中间数据（含转录文本）。已知问题，将在后续版本修复 |
| 8 | **多实例同时运行不受支持** | 多进程写同一个 SQLite 可能报错，请单实例使用 |

> 第 7 条涉及隐私（转录文本残留），会在 v0.1.x 优先处理。

## 第三方组件与合规

- **FFmpeg 不打包进 exe**。它是 GPL 构建，打进 MIT 项目会造成许可冲突；
  本程序在首次使用时把它下载到用户目录，并以**独立进程**调用（GPL FAQ 认可的聚合方式）。
- `pyJianYingDraft`（Apache-2.0）与 `OpenTimelineIO`（Apache-2.0）作为库引用。
- **不随包分发任何字体**，使用系统已装字体。
- **不内置任何 BGM**，`bgm` 目录留给你自行放入有授权的音乐。

完整清单见 [README](../README.md#第三方组件与许可)。
